# CAD to Career — Phone to Desktop Plan

## Stage 1: Android phone — lessons 1–8
Read modules, practice units and coordinates, and complete the interactive 2D CAD lab in your phone browser. A keyboard is optional. Tap a shape, type dimensions in millimeters, check tolerance, and export JSON/SVG. Keep exported backups because local browser state does not sync between devices.

## Stage 2: Desktop drafting — lessons 5–8
Install LibreCAD (free and open source). Create a metric drawing; use absolute coordinates and object snaps. Add dimensions and layers, export DXF and inspect scale on reimport. Re-create Project 1 in LibreCAD.

## Stage 3: Desktop parametric CAD — lessons 9–16
Install FreeCAD. Create sketches with meaningful geometric and dimensional constraints. Build pads, pockets, holes and fillets. Keep editable FCStd and export STEP plus a dimensioned drawing PDF. Autodesk Fusion may be used as an alternative if its current personal-use licensing applies; paid software is not required.

## Stage 4: Desktop visualization — lessons 17–18
Install Blender. Build an editable product mesh and render with materials and deliberate lighting. Use Blender for communication and mesh editing, not as a replacement for a dimensionally constrained manufacturing model.

## Stage 5: Portfolio and independent design — lessons 19–20
Complete Projects 2–5 with evidence. Inspect all neutral exports. For the capstone, show independent decisions, native history, dimensions, manufacturing considerations and a short rationale.

## Hardware
For detailed 3D work, choose a desktop/laptop with a modern multithreaded CPU, at least 16 GB RAM (32 GB preferred for complex scenes), SSD storage, and a mouse. A discrete GPU benefits Blender rendering. Exact hardware depends on project complexity and software versions.

## Skill evidence checklist
- [ ] Accurate dimensions and tolerances
- [ ] Correct coordinate systems and units
- [ ] Geometrically and dimensionally constrained sketches
- [ ] Native editable models and understandable feature history
- [ ] STEP/DXF interchange checked after export
- [ ] Dimensioned PDF drawings
- [ ] Independent problem-solving notes
- [ ] Reviewed, authentic portfolio submissions

*This roadmap does not certify skill or guarantee employment.*
